<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Postgres data → rendered table | Data originates from community-maintained GitHub sources (Phase 1 ingestion), not user input, but is rendered directly into the DOM |
| Row `url` field → outbound anchor | Every row's `url` (source-controlled, from GitHub data) becomes a live `<a href>` the user can click |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | outbound `url` anchors (row link to source/application) | low | mitigate | Every external anchor renders with `target="_blank" rel="noopener noreferrer"` so a malicious/compromised upstream `url` cannot access `window.opener` or leak referrer data |
| T-02-02 | Information Disclosure | rendered `raw` JSONB / row text fields (title, description) | low | accept | React's default JSX escaping prevents XSS from upstream markdown/JSON content; `dangerouslySetInnerHTML` is never used in this plan's rendering path |
| T-02-SC | Tampering | npm installs (shadcn CLI + `lucide-react`, `class-variance-authority`, `clsx`, `tailwind-merge`, `@radix-ui/react-tabs`, `@radix-ui/react-slot`) | high | mitigate | Package-legitimacy gate + blocking human checkpoint (Task 1) for all [ASSUMED] packages, verified against npmjs.com before install |

</threat_model>
