## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cliente (componente `SendToAiButton`, Plan 07-02) → `generateApplyPrompt` Server Action | El `externalId` viaja como argumento no confiable de una Server Action invocada desde un componente cliente; todo lo demás (url/title/company/perfil) se relee server-side, nunca se acepta del cliente |
| Página de la oportunidad (contenido arbitrario de terceros) → sesión externa de Claude Code con Playwright MCP | El prompt generado aquí es la única mitigación disponible en este límite — mismo "lethal trifecta" de research/PITFALLS.md Pitfall 5 |
| `generateApplyPrompt` → prompt copiado / pegado en una sesión externa | El secret embebido cruza este límite intencionalmente (riesgo ya aceptado en 06-CONTEXT.md/06-SECURITY.md como T-06-07) |
