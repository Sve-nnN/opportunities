<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub raw content -> ingestion parser | External, community-editable, unversioned data crosses here — treated as untrusted input |
| HTTP client -> `/api/sync` route | Any network client that can reach the app's port crosses here, even before Phase 4's public domain exists |
| Env vars -> process | `GITHUB_PAT` and `SYNC_TRIGGER_SECRET` cross from Dokploy/local `.env` into the running process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | `src/ingestion/sources/student-benefits.ts` | medium | mitigate | zod validation on every parsed row; malformed entries are logged and skipped, never inserted raw |
| T-01-02 | Information Disclosure | `GITHUB_PAT` env var | high | mitigate | PAT is read-only, fine-grained, expiring (user_setup); never logged in `error_message` or console output — task 2 must not log full response bodies containing auth-adjacent data |
| T-01-03 | Spoofing | `POST /api/sync` route | medium | mitigate | shared-secret `Authorization: Bearer` check (task 3); rejects any request without the exact `SYNC_TRIGGER_SECRET` |
| T-01-04 | Denial of Service | `POST /api/sync` route (repeated triggering) | low | accept | single-user personal app with no public DNS entry until Phase 4; the shared-secret check already limits callers to Juan; formal rate-limiting deferred as unnecessary complexity at this scale |
| T-01-05 | Repudiation | sync failures with no record | low | mitigate | `sync_log.error_message` captures every failure with a timestamp, so silent data-loss (PITFALLS.md UX Pitfall) is always traceable |

</threat_model>
